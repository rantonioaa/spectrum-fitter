# Spectrum Fitter — pinned, known-working stack
#
# These pins are deliberate. The modelling code was written in 2020-2021 and
# uses APIs that were removed from later releases. Do NOT blanket-upgrade:
# each pin below is load-bearing. See CHANGELOG.md for what breaks if you move.
#
#   numpy <2.0    -> ndarray.newbyteorder() exists (removed in numpy 2.0)
#   astropy 5.3.x -> required by specutils 1.3
#   specutils 1.3 -> Spectrum1D(spectral_axis=..., flux=...) is the live API.
#                    specutils >= 1.4 deprecates it, >= 1.9 removes it.
#   pandas 2.1.x  -> read_csv(delim_whitespace=True) still accepted
#                    (removed in pandas 3.0)
#   pyarrow 14    -> pyarrow >= 15 is built against the numpy 2 ABI and refuses
#                    to import alongside numpy 1.26 (streamlit imports pyarrow)
#   streamlit     -> any version >= 1.14 is fine; widget keys are now unique
